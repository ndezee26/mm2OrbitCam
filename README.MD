This is a LUA script for use with MM2Hook that enables a GTA San Andreas style orbiting camera controlled by the mouse.

Tested on MM2Hook Gold 2026-08-29

To install:
Place the main.lua file into the LUA directory within the MM2 game folder

To use:
Press the "O" key on the keyboard to toggle the orbit cam or press and hold the right mouse button.
Scrolling with the mouse wheel controls zoom
